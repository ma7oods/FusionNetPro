# FusionNet Pro 3.0.1 — طريقة العمل والتثبيت وحالة الإصلاح

آخر تحديث: 2026-10-23 · بعد مراجعة كاملة للمشروع وبناء وتشغيل كل المسارات.

### تحديث دقة الاتصال — 2026-10-23

- قياس السرعة يحسب فرق العدادات لكل محول مستقلًا؛ المحول الجديد أو العائد بعد الانقطاع يبدأ بخط أساس جديد، فلا تُحسب بياناته القديمة كقفزة سرعة.
- فحص DNS يطابق السؤال والرقم التعريفي، ويرفض الردود المبتورة ومؤشرات ضغط الأسماء غير الصالحة؛ يحافظ على قبول الأسماء المضغوطة واختلاف حالة الأحرف.
- أُضيفت ٢٤ حالة اختبار للشبكة. نجحت الاختبارات الـ٢٩٨ كاملة، دون تخطي؛ احتاجت اختبارات حفظ الملفات التشغيل خارج عزل الملفات.
- نجح الفحص الحي للستة خوادم DNS الموصى بها وقراءة عدادات السرعة، دون تطبيق DNS أو تغيير إعدادات الشبكة.
- قواعد التحقق راجعت [RFC 1035](https://www.rfc-editor.org/rfc/rfc1035) و[RFC 5452](https://www.rfc-editor.org/rfc/rfc5452).

إعادة الفحص الحي (يحتاج .NET 10 SDK واتصالًا بالإنترنت):

```powershell
dotnet run --file qa/network-smoke.cs
```

القياس خاص باتصال الجهاز وقت الفحص، وليس ضمانًا لخفض بنق الألعاب. فحص DNS الحالي يقيس UDP فقط ويرفض الرد المبتور؛ لا يتضمن إعادة المحاولة عبر TCP.

## 1. ما هو البرنامج

**FusionNet Pro** تطبيق Windows موحّد (.NET 10 + WPF) يجمع ثلاث أدوات سابقة في مكان واحد:

| المشكلة التي يحلها | ما يقدّمه |
|---|---|
| أولوية الشبكة أثناء اللعب | قياس ping وسرعة، كشف الألعاب تلقائياً، إيقاف الخدمات، تعديلات سجل مُ reversible |
| وضع التركيز أثناء اللعب | تجميد/تقييد التطبيقات، وضع ملء الشاشة، خطة الطاقة، Game Mode/DVR، اختصار لوحة مفاتيح، استعادة بعد الانهيار |
| حارس جدار الحماية للألعاب | حظر لكل تطبيق عبر Windows Firewall، ملفات تعريف ألعاب، كتالوج تطبيقات مُدارة |

الواجهة **عربية أولاً (RTL)** مع مفتاح تبديل للإنجليزية، وكل النصوص مترجمة.

### الصفحات الثماني

`Ctrl+1` … `Ctrl+8` للتنقل السريع:

| المفتاح | الصفحة | المحتوى |
|---|---|---|
| Ctrl+1 | لوحة التحكم | الحالة العامة، Frequent Mode، الأهداف، الأنشطة الأخيرة |

| Ctrl+3 | DNS | مزوّدو DNS، قياس سرعة، تبديل/تخصيص، IP العام |
| Ctrl+4 | تحسين الشبكة | ٢١ تعديلاً مُجمّعاً، توصيات، تبديل لكل تعديل، زر "تراجع عن الكل" |
| Ctrl+5 | الألعاب | ملفات التعريف، وضع يدوي/تلقائي، ألعاب مخصصة، اكتشاف الألعاب الجارية |
| Ctrl+6 | شاشة الأمان | إدارة التطبيقات المحمية، الحظر عبر جدار الحماية |
| Ctrl+7 | النشاط | سجل العمليات، تصفية، تصدير |
| Ctrl+8 | الإعدادات | اللغة، اللون، الخدمات، الاختصار، ترقية الصلاحيات، البيانات |

## 2. التثبيت

### أ) المعالج الكامل (موصى به)

شغّل `dist\FusionNetPro-Setup-3.0.1.exe` ← معالج رسومي:

- المسار الافتراضي: `%LOCALAPPDATA%\Programs\FusionNet Pro`
- اختصار في قائمة ابدأ + على سطح المكتب
- قيد في "إضافة/إزالة البرامج" مع زر إزالة
- `uninstall.ps1` داخل مجلد التثبيت (إزالة صامتة ومؤتمتة)

سطر أوامر:

```powershell
# تثبيت صامت في مسار مخصص
.\FusionNetPro-Setup-3.0.1.exe /S /D="D:\FusionNetPro" /nolaunch

# إزالة صامتة
.\FusionNetPro-Setup-3.0.1.exe /uninstall /quiet
```

### ب) بدون تثبيت

| الملف | الوصف |
|---|---|
| `dist\FusionNetPro-3.0.1.exe` | ملف واحد، ٦٦.٩ ميجابايت، شغّله مباشرة |
| `dist\FusionNetPro-3.0.1-portable.zip` | نفس الملف + README |
| `dist\SHA256SUMS.txt` | بصمات SHA-256 للتأكد من سلامة الملفات |

> **الملفات غير موقّعة (unsigned).** ويندوز سيعرض "Open File - Security Warning" → اضغط **Run**.
> نسخة الملف الواحد تستخرج مكتباتها الأصلية في `%TEMP%` عند **أول تشغيل لكل نسخة جديدة**، فتحتاج مجلد Temp قابلاً للكتابة.

### ج) بناء الإخراج من المصدر

```powershell
.\installer\build-installer.ps1          # يبني التطبيق + الحمولة + المثبّت + dist\app
dotnet build FusionNet.slnx              # بناء
dotnet run --project qa\TestRunner\TestRunner.csproj   # ٢٩٨ اختبار
.\qa\test-installer.ps1                  # اختبار التثبيت والإزالة
.\qa\check-readonly-bindings.ps1         # فحص صفحات الـXAML
```

## 5. قيود معروفة

1. **وضع الإغلاق الصارم (`StrictLockdownService`)** عنصر نائب فاشل بأمان عمداً — لا يُعدّل قبل كتابة النسخة الحقيقية.
2. **الملفات غير موقّعة** → تنبيه الناشر عند التشغيل.
3. **نسخة الملف الواحد** تحتاج `%TEMP%` قابلاً للكتابة عند أول تشغيل.
4. **لا يوجد توقيع كود** — خطوة إصدار رسمية مقترحة.
5. **قيود بيئة المراجعة:** البيئة التي أُجرت فيها المراجعة تمنع أي ملف ثنائي **غير موقّع** من الكتابة خارج مجلد المشروع. لذلك تعذّر التحقق هنا من: قيد السجل في "إضافة/إزالة البرامج"، اختصار قائمة ابدأ، وإطلاق النسخة **المثبَّتة** (تحتاج استخراج `%TEMP%`). كل خطوات ويندوز قياسية ولا يتوقّع أن تظهر على جهاز عادي.
