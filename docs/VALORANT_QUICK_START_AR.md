# تجربة FusionNet Pro 3.2.2 مع VALORANT

أغلق FusionNet القديم بالكامل، بما فيه أيقونته قرب الساعة. افتح `تشغيل FusionNet Pro.exe` في جذر المشروع للتجربة دون تثبيت، أو `تثبيت FusionNet Pro.exe` للتثبيت. لا حاجة لتثبيت .NET.

1. شغّل فالورانت طبيعيًا من Riot Client، وافتح **Game Boost — وضع اللعب** ثم **Scan**.
2. اضغط **عينة استهلاك الشبكة — ETW** لقياس الرفع والتنزيل لكل عملية بعد مراجعة الموافقة وطلب Windows للمساعد. العينة نحو5 ثوانٍ؛ البيانات المفقودة غير متاحة، وليست الأرقام تحديثًا مستمرًا.
3. اضغط **اقتراح محلي مبني على القياس**، وراجع اختيارات التطبيقات المؤهلة وأزل أي تطبيق تحتاج اتصاله. الاقتراح لا يحظر شيئًا.
4. حدد المدة ثم اضغط **بدء Game Mode — معاينة وموافقة**. اقرأ المسارات والقواعد والمدة والمهمة المستقلة قبل الموافقة. انتظر **Active**.
5. عند الانتهاء اضغط **Stop & Restore** وانتظر **Restored**. **Pending** يعني أن الاسترجاع غير محسوم؛ لا تحذف السجل أو المهمة يدويًا.

الحظر كامل لاتصال EXE الصادر ويشمل كل نسخه، دون تقييد سرعة. تُستثنى الألعاب وRiot/Vanguard والنظام والخدمات وDNS وتطبيقات الأمان والدور المجهول. التحقق محافظ وقد يرفض تطبيقاتك؛ لا تتجاوز الرفض بتغيير الأسماء.

تُحفظ حالة محمية في `%ProgramData%\FusionNetPro.GameBoost` ثم تُجهّز مهمة SYSTEM مستقلة عند الإقلاع وكل دقيقة عند الحاجة قبل أول قاعدة. المساعد يراقب انتهاء المدة/التطبيق/الألعاب التي رصدها Scan. إذا فُحص الجهاز قبل تشغيل اللعبة فلا توجد هوية لعبة حية لمراقبة خروجها؛ أعد Scan بعد تشغيلها أو استخدم Stop والمدة. تعطل المساعد والتطبيق معًا قد يؤخر الاسترجاع إلى محاولة المجدول التالية؛ توفر Task Scheduler مطلوب.

لا تشغّل Fusion القديم والجلسة الجديدة معًا. التفعيل التلقائي لوضع Fusion يشتغل لما تبدي لعبة مراقبة، إذا الخيار مفعّل والبرنامج شغال كمسؤول (من 3.3.3 الاختصار يفتحه كمسؤول تلقائيًا والويندوز يطلب موافقة كل مرة)، ويرجّع كلشي لما تطلع من اللعبة. لا تضغط «تطبيق الكل» أو تغيّر TCP والطاقة والخدمات أثناء المقارنة الأولى. خفض أولوية CPU/IO ليس حدًا لسرعة الشبكة. Game Boost لا يغير DNS أو إعدادات الجدار العامة.

فعّل Network RTT وPacket Loss داخل اللعبة وقارن على نفس السيرفر في التدريب أولًا. بنق 1.1.1.1/8.8.8.8 في البرنامج ليس بنق سيرفر فالورانت. تغيير DNS ليس ضمانًا لخفض زمن المباراة؛ البرنامج لا يوفر VPN أو مسار توجيه خاصًا.

**لم تُجرَ تجربة داخل مباراة أو مع Firewall/Task Scheduler/ETW حية أثناء التطوير.** الملفات غير موقعة ولا يوجد اعتماد من Riot؛ الاختبارات المعزولة لا تثبت توافق كل إصدار Vanguard أو العتاد.

راجع [دليل الوحدة الكامل](GAME_BOOST_GUIDE_AR.txt) للفحص المحلي وAI الاختياري والتخزين وLibreHardwareMonitor. AI يحتاج موفرًا خاصًا بك وموافقة كل إرسال؛ تكامل LHM قراءة WMI من الأداة الخارجية فقط، دون DLL أو driver مضمّن.
