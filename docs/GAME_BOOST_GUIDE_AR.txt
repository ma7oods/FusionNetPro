FusionNet Pro 3.2.2 — Windows 10/11 x64

التشغيل والتثبيت
شغّل FusionNetPro.exe أو اختصار FusionNet Pro. حزمة .NET مضمّنة.
أغلق النسخة القديمة بالكامل قبل التحديث. لا يلزم Administrator لفتح الواجهة.
التثبيت لحسابك الحالي؛ عند رفض الوصول يعرض المثبّت إعادة محاولة بصلاحية المسؤول باختيارك.

لتجربة فالورانت
1. شغّل VALORANT طبيعيًا ثم افتح Game Boost واضغط Scan. لا تضغط تطبيق الكل في محسّن الشبكة.
2. لقياس نقل كل عملية اضغط «قياس رفع وتنزيل التطبيقات (5 ثوانٍ)» وراجع الموافقة. يطلب المساعد فقط صلاحية Administrator.
3. اضغط الاقتراح المحلي المبني على القياس، أو حدد تطبيقات خلفية مؤهلة تعرفها. لم يُحظر شيء بعد.
4. اضغط بدء Game Mode وراجع التطبيقات والمسارات والمدة والقواعد ومهمة الاسترجاع ثم وافق إن رغبت.
5. لا تعتبر الجلسة مفعّلة حتى تظهر Active. عند الانتهاء اضغط Stop & Restore وانتظر Restored.

Game Boost يحظر اتصال EXE الصادر كاملًا مؤقتًا لكل نسخه، ولا يقيّد سرعته.
تُستثنى الألعاب وRiot/Vanguard والنظام وDNS والخدمات وتطبيقات الأمان والدور المجهول.
يحفظ حالة محمية ويُجهّز مهمة مستقلة بحساب SYSTEM قبل أول قاعدة؛ تعمل عند الإقلاع وكل دقيقة عند الحاجة.
الاسترجاع بعد تعطل المساعد يعتمد على توفر Task Scheduler، وقد يتأخر إلى المحاولة التالية.
إذا بدأ Scan قبل تشغيل اللعبة فلا توجد هوية لعبة حية لمراقبة خروجها؛ استخدم Stop أو المدة المحددة.
لا يغير Game Boost إعدادات Firewall العامة أو DNS. إعدادات Fusion القديمة منفصلة وأوسع نطاقًا.
التفعيل التلقائي القديم متوقف عند بدء التطبيق حتى لو بقي التفضيل محفوظًا.

Security Monitor
Scan يدوي للعمليات والموارد والاتصالات ومعلومات Defender وStartup والخدمات والمهام والتواقيع.
لا يبدأ فحص Defender أو يعالج ملفات. راجع التغطية والأدلة؛ الملاحظات ليست تشخيص إصابة.
البيانات المفقودة تظهر غير متاحة. ETW عينة قصيرة مؤرخة، وليست قراءة مستمرة أو بنق اللعبة.
تحليل التخزين يدوي لمجلد تختاره فقط مع حدود قراءة وموافقة منفصلة؛ لا حذف.
قائمة صيانة شهرية يدوية؛ لا جدولة فحص شهري في هذه النسخة.

AI اختياري
يعمل الفحص المحلي بلا API. أدخل رابط Responses API عبر HTTPS والنموذج ومفتاح حسابك إن أردت التحليل السحابي.
راجع الحمولة ثم وافق على كل إرسال؛ قد توجد رسوم لدى الموفر. المفاتيح مشفرة بـDPAPI لحساب Windows ومربوطة بالرابط.
النتيجة نص استشاري لا ينفذ أوامر. تصدير التقرير يحفظ تقريرًا محليًا بعد مراجعة البيانات.

LibreHardwareMonitor والأدوات الرسمية
تفتح الأزرار صفحات LHM وAutoruns وProcess Explorer الرسمية فقط؛ لا تثبيت أو تشغيل تلقائي.
حساسات LHM تُقرأ من WMI إذا شغّلته أنت وفعّلت WMI. لا DLL أو driver مضمّن ولا تحكم بالمراوح/الفولتية.
راجع THIRD-PARTY-NOTICES.txt أو زر تراخيص المكونات. التراخيص مضمنة داخل EXE أيضًا.

حدود التجربة
لم تُجرَ تجربة داخل فالورانت أو إنشاء قواعد Firewall/مهام استرجاع أو قياس ETW حي أثناء التطوير.
الاختبارات المعزولة والبناء لا تثبت التوافق على جهازك أو خفض البنق. الملفات غير موقعة رقمياً.
بنق 1.1.1.1 في لوحة القيادة ليس بنق سيرفر اللعبة؛ قارن RTT وفقد الحزم داخل VALORANT نفسها.
إذا ظلت الحالة Pending فلا تفترض زوال الحظر؛ اطلب Stop & Restore وراجع حالة الاسترجاع.
الإنهاء القسري لعامل ETW قد يترك جلسة تتبع يتيمة حتى إعادة التشغيل.

النسخ الاحتياطي
حالة File History ليست إثبات نسخة ناجحة. تحقق من الوجهة وآخر نجاح في Windows Backup/File History.
يمكن إعداد File History من لوحة تحكم Windows باختيار قرص احتياطي ثم تجربة استرجاع ملف صغير.

الإزالة
أوقف الجلسة وانتظر الاسترجاع قبل تحديث البرنامج أو إزالته.
من إعدادات Windows > التطبيقات > FusionNet Pro > إزالة، أو uninstall.ps1 داخل مجلد التثبيت.
تبقى بياناتك في %LOCALAPPDATA%\FusionNetPro. لا تحذف سجل ProgramData يدويًا أثناء جلسة معلقة.


الجديد في3.2.2
واجهة موحدة بألوان أوضح وتبويبات للعمليات والتنبيهات والمصادر والتخزين وAI. بحث باسم العملية أو PID أو المسار، ومرشح لنشاط النقل المقاس وCPU/RAM فوق5%. لا تعتبر الوصف حسب اسم العملية إثبات هوية أو أمان.
زر جلسة اللعب في الشريط الجانبي ولوحة القيادة يفتح Game Boost للمراجعة؛ لا يبدأ الحظر. تحكم Fusion القديم داخل الخيارات المتقدمة.
من أدوات التشخيص والعتاد: أدخل نطاقًا وعنوان IP لخادم DNS ونوع السجل، ثم فحص السجلات. يبدأ الاستعلام عند الضغط فقط عبر DNS المنفذ53 غير المشفر، وقد يستخدم TCP بدل UDP للردود المبتورة. لا يغير DNS الجهاز ولا يقيس بنق سيرفر اللعبة. تُعرض السجلات وTTL والتوقيت والرد الجزئي بوضوح.
زر تحديث الحساسات يقرأ عينة LibreHardwareMonitor WMI التي توفرها الأداة الخارجية؛ لا قياسات مختلقة ولا تثبيت driver. النتيجة مؤرخة وليست قراءة مستمرة.
المكونات: DnsClient.NET1.8.0 (Apache-2.0)، Microsoft TraceEvent3.2.8 (MIT)، وLibreHardwareMonitor الخارجي. التراخيص داخل EXE وTHIRD-PARTY-NOTICES.txt. لا اختبار سرعة أو أدوات التقاط حزم تعمل تلقائيًا بالخلفية.

واجهة 3.2
لوحة القيادة تعرض حالة الجلسة وقياس الاتصال مع مصدره. افتح Game Boost للفحص والمراجعة والبدء.
فاحص سجلات DNS والحساسات في «أدوات التشخيص والعتاد»؛ كلاهما يدوي ولا يغيّر DNS في Windows.
نصوص الواجهة والموافقة تدعم العربية/الإنجليزية؛ الأدلة والنتائج الملتقطة وAI تبقى بلغتها الأصلية.
لم تُجرَ تجربة حية للجدار أو التعطل/إعادة التشغيل أو التثبيت أو اللعبة؛ نتائج الاختبارات المعزولة ليست بديلًا عنها.

تصحيحات3.2.2
اكتشاف جلسة تحتاج استرجاعًا لا يتوقف بسبب تراكم أكثر من2000 سجل قديم. إذا فشل تنظيف مهمة الاسترجاع، تُحفظ Pending عند إمكان الكتابة وتبقى المهمة للمحاولة مجددًا.
التقرير المحلي يحفظ شرح التنبيهات وأدلتها وتوصياتها والقياسات غير المتاحة بوضوح، بعد معاينة النص الذي سيُحفظ. قد يحتوي أسماء ومسارات خاصة؛ لا ترسله للآخرين قبل مراجعته. التصدير لا يرسل بيانات للسحابة، وتحليل AI يبقى منفصلًا واختياريًا وبموافقة لكل إرسال.
تغطية النسخ الاحتياطي وسجل استخدام البرامج جزئية: وجود خدمة أو إعدادات أو تاريخ تثبيت لا يثبت نجاح نسخة أو تاريخ استعمال التطبيق.
